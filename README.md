# 🍽️ Uma Pitada de Tudo

Um site de receitas desenvolvido como projeto acadêmico de UI/UX, com o objetivo de apresentar receitas de forma organizada, visualmente agradável e fácil de navegar.

## 📖 Sobre o projeto

O Uma Pitada de Tudo é um site dedicado ao universo da culinária, reunindo receitas, ingredientes e conteúdos relacionados à cozinha.

O projeto foi desenvolvido para explorar conceitos de design de interfaces e experiência do usuário, buscando oferecer uma navegação simples e intuitiva.

## ✨ Funcionalidades

- Apresentação de receitas.
- Navegação entre as seções do site.
- Exibição de imagens e conteúdos culinários.
- Interface desenvolvida com foco na experiência do usuário.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 💻 Como executar o projeto

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador.

Para uma experiência melhor durante o desenvolvimento, recomenda-se utilizar a extensão Live Server do VS Code.
